# 流す

保存したパイプは、作業台の「流す」から流せます。端末で打ってもかまいません。

作業台の右の欄の下にある節「流す」に依頼メモを書いてボタンを押すと、拡張が `pipe-in` を起こします。段の確認は端末で答えます。実行ファイルは設定 `pipe-in.command` で決めます。

開発フロー（`--pipe` を付けない流れ）は作業台から流せません。端末か Claude Code の会話で、対象のプロジェクトと要件メモを渡して 1 行を貼ります。次の 1 行は開発フローの形です。

```bash
pipe-in --project ~/src/myapp --text "ユーザー一覧に CSV 出力ボタンを追加したい"
```

段ごとに Claude Agent SDK を呼ぶので、利用料がかかります。対象は git 管理下にして、作業用のブランチで流してください。
