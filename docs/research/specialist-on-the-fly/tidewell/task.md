下の「Tidewell 共有ソース許諾書 2.1」（架空のライセンス）と、6つの表（CSV）を読み、行為の表 `acts.csv` に出てくる 27 社それぞれについて、その会社がこの許諾書のもとでどう扱われるかを、4つの区分から1つ選んでください。

表の場所：`このフォルダ`

| ファイル | 中身 |
| --- | --- |
| `companies.csv` | 会社の一覧。売上高（百万円）と従業員数は、直近に終了した事業年度のもの。種別は 会社・学校（学校教育法に定める学校）・非営利法人 |
| `shares.csv` | 誰が誰の議決権を何 % 持っているか。ここに無い分は、会社でない個人などが持っている |
| `acts.csv` | 会社が Tidewell でしている行為。1社に複数の行があることがある |
| `deliveries.csv` | 「提供」の行為で、複製物をいつ・誰に・何者に渡したか。相手は重複しない |
| `usage.csv` | 「ネットワーク」の行為で、その月にネットワークを通じて機能を使った者の内訳と人数。載っている月がすべて |
| `suits.csv` | Tidewell が特許を侵害すると主張して、許諾者に対して起こされた手続。「反訴」は、許諾者が先に起こした手続の中でのもの |

表の読み方：

- `deliveries.csv` の「渡した相手」と `usage.csv` の「使った者」が `会社:K07` の形のときは、その会社（とその従業員）を指す。
- `usage.csv` の「自社」は、その会社の役員と従業員。「構成員」は、別紙でいう構成員。「第三者」は、それ以外の外部の者。
- 受託者は、どれも、その会社のためだけに使う受託者。消去の義務の期限は、かっこの中に書いてある。
- 「変更の種類」が「プラグイン」の行は、本体のソースコードは変更せず、書いてある接続点だけを通じて動く別のプログラムを作ったもの。

判断の決まり：

- 判断の基準日は 2026年11月13日。
- この許諾書と表に書いてあることだけで判断する。実在の法律やほかのライセンスの知識は持ち込まない。
- 1社に複数の行為があるときは、いちばん重い区分を答える。重い順は `X` > `D` > `N` > `F`。

## 区分

- `F`：許される。義務は無い。
- `N`：許される。表示義務だけを負う。
- `D`：許される。表示義務と開示義務を負う。
- `X`：許されない行為がある（許諾が終了している場合を含む）。

## 決まり

- 読むだけの作業です。答えを書くファイル以外は作らない・書き換えない。ほかの答えのファイルは見ない。
- Web は使わない（架空の文書なので、調べても出てこない）。
- 答えは指定された1つのファイルに、下の形の JSON だけを書く。キーは会社ID（27 社ぶん）、値は `F` `N` `D` `X` の1文字だけ。説明・出典・記号以外の文字を値に入れない。
- 最後の返事は「書いた」の1行だけにする。

# Tidewell 共有ソース許諾書 2.1


Tidewell は、時系列データベースのソフトウェアである。許諾者は Tidewell 財団。

## 第1条（定義）

1. 「本ソフトウェア」とは、この許諾書が付された Tidewell の各版をいう。
2. 「利用者」とは、この許諾書のもとで本ソフトウェアを使う者をいう。利用者の役員と従業員は、利用者に含む。
3. 「企業集団」とは、誰にも議決権の過半数を持たれていない者と、その者が議決権の過半数を直接または間接に持つすべての者の全体をいう。ある者が「間接に持つ」議決権とは、その者が議決権の過半数を（直接または間接に）持つ者が持っている議決権をいい、その全部を、自らが直接に持つ議決権に加えて数える。議決権の過半数を誰にも持たれておらず、誰の過半数も持っていない者は、企業集団に属さない。
4. 「第三者」とは、利用者以外の者をいう。ただし、次の者は第三者に含めない。
   - (a) 利用者と同じ企業集団に属する者（その役員と従業員を含む）
   - (b) 利用者のためだけに本ソフトウェアを使う受託者であって、委託の終了から30日以内に複製物を消去する義務を、契約で負っている者
5. 「改変」とは、本ソフトウェアのソースコードを変更すること、または本ソフトウェアのソースコードの一部を他のプログラムに取り込むことをいう。改変したものを「改変版」という。次のことは改変に当たらない。
   - (a) 設定ファイルの値を変えること
   - (b) 別表Bの拡張点だけを通じて動く、別のプログラムを作ること。ただし、そのプログラムが本ソフトウェアのソースコードを10行以上含むときは、そのプログラムの全体を改変版とみなす。
6. 「提供」とは、本ソフトウェアまたは改変版の複製物（実行形式とコンテナイメージを含む）を、第三者に渡すことをいう。
7. 「ネットワーク提供」とは、複製物を渡さずに、ネットワークを通じて、本ソフトウェアまたは改変版の機能を第三者に使わせることをいう。
8. 「小規模利用者」とは、直近に終了した事業年度の売上高が5億円未満で、かつ、その年度の末日の従業員が50人以下の利用者をいう。企業集団に属する利用者については、企業集団の全体を合算して判定する。
9. 「競合サービス」とは、別表Aの主要機能のいずれかを主たる価値とするサービスを、有償で、第三者にネットワーク提供することをいう。
10. 「変更日」とは、本ソフトウェアの各版について、その版の公開日から4年を経過した日をいう。
11. 「表示義務」とは、この許諾書の写しと、許諾者の帰属表示を、相手が読める形で付ける義務をいう。
12. 「開示義務」とは、改変した部分のソースコードを、この許諾書と同じ条件で、相手が入手できるようにする義務をいう。

## 第2条（内部での利用）

利用者は、自らの業務のために、本ソフトウェアを複製し、実行し、改変することができる。この利用に義務は無い。

## 第3条（改変していないものの提供）

利用者は、改変していない本ソフトウェアを提供することができる。このとき、利用者は表示義務を負う。

## 第4条（改変版の提供）

利用者は、改変版を提供することができる。このとき、利用者は表示義務と開示義務を負う。ただし、小規模利用者は、改変版を提供した相手の数が、累計で100者以下である間は、開示義務を負わず、表示義務だけを負う。

## 第5条（ネットワーク提供）

1. 利用者は、改変していない本ソフトウェアをネットワーク提供することができる。この利用に義務は無い。
2. 利用者は、改変版をネットワーク提供することができる。ある暦月に、その機能を使った第三者の数が1万を超えたときは、利用者は、その月以降、表示義務と開示義務を負う。1万を超えた月が無い間は、義務は無い。
3. 第4条ただし書は、本条には準用しない。

## 第6条（競合の制限）

1. 利用者は、本ソフトウェアまたは改変版を、競合サービスに使ってはならない。
2. 前項は、次の場合には適用しない。
   - (a) その版の変更日以後に、その版（その版の改変版を含む）を使う場合
   - (b) 別紙の追加許諾の条件を満たす場合
3. 本条が適用されない場合も、第2条から第5条までは引き続き適用する。

## 第7条（特許についての終了）

1. 利用者、または利用者と同じ企業集団に属する者が、本ソフトウェアが特許を侵害すると主張して、許諾者に対する訴えを起こしたときは、その訴えを起こした日に、この許諾書による利用者への許諾は、すべて終了する。
2. 前項は、次の場合には適用しない。
   - (a) 許諾者が先に起こした手続の中での反訴として主張する場合
   - (b) 訴えを起こした日から60日以内に、その訴えを取り下げた場合。この場合、許諾は終了しなかったものとみなす。

## 第8条（優先する順）

第6条と第7条は、第2条から第5条までに優先する。
