## 置き方

- 1つの調査を1つのフォルダ（`docs/research/<英小文字・数字・->/`）にし、本文は `README.md` に書きます。本文には「問い・結論・方法・結果・限界・pipe-in への示唆・やり直し方」の節を置きます。
- スクリプトと集計の結果は置いてよいですが、生のデータ（モデルの出力の全部など）は大きくなるので置きません。
- 足したら上の表に1行足します（`tests/test_research.py` が、表がすべてのフォルダを指しているかを検査します）。
- 手元の事情（ユーザー名の入ったパス・メールアドレス）を書かないのは、ほかの文書と同じです。
