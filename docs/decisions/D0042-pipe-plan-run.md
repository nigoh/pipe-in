# D0042 計画ボードのカードから、新しいセッションで /pipe-in を始める

## 目的

計画ボード（`/pipe-plan`）のカードで「実行」を押すだけで、Claude Code Remote に新しいセッションを作り、`/pipe-in <カードの題とメモ>` を流し始められるようにする。会話を開いてコマンドを打つ手間を省き、始めたセッションの状態を、そのカードの上で見られるようにする。

## D0029 から置き換える点

D0029 は書き換えない。次の2点だけを、この記録が置き換える。

- 「ページが宣言する道具は `list_sessions` 1つだけ」→ `list_sessions`・`create_session`・`list_environments` の3つ。D0029-AC-11・AC-12 の検査は、3つに合わせた D0042-AC-01・AC-03 に置き換えた。
- 「ページから作業を始めない」→ 確認の画面で人が「作る」を押したときだけ、新しいセッションを作る。`send_message`・`archive_session`・`interrupt_session`（送る・止める・アーカイブ）は、今も呼ばない・宣言しない。D0029-AC-06（URL を書かない）の検査は、実際のセッション ID と手元のパスまで広げた D0042-AC-11 に置き換えた。

## 機能要件と受け入れ基準

- FR-01 カードに「実行」を出す。押すと確認を出し、「作る」で `create_session` を呼び、最初の言葉に `/pipe-in <題とメモ>` を渡す。
  - D0042-AC-04 `create_session` を呼ぶ関数は、確認フォームの送信の処理からだけ呼ばれる。
  - D0042-AC-05 `create_session` の引数に `environment_id` が必ず入り、環境が空なら呼ばない。
  - D0042-AC-08 最初の言葉は `/pipe-in ` に題とメモを付けて作る。題が空のカードでは出さない。
  - D0042-AC-20 送る言葉は編集でき、先頭が `/pipe-in ` でない（または後ろが空）なら呼ばない。
  - D0042-AC-21 引数は `prompt`・`source_url`（`REPO`）・`environment_id`・`title` だけ。`permission_mode`・`model`・`--auto`・`--artifact` は付けない。
  - D0042-AC-14（画面・手で）確認に、送る言葉・環境の選び・利用料の注意が見え、「やめる」で何も作られない。
- FR-02 押せるのは書ける人だけ。動いているセッションがあるカードには出さない。
  - D0042-AC-06 「実行」の条件に `canWrite` がある。
  - D0042-AC-07 条件に、セッションの一覧を読み終えたことと「動いていない」がある。
  - D0042-AC-15・AC-16（画面・手で）書けない人には出ない。動いているセッションがあるカードには状態の札が出る。
- FR-03 環境は `list_environments` で選ぶ。
  - D0042-AC-19 `state` が `active` の環境だけを選べ、1つなら自動で使い、複数なら選ぶ。選んだ環境は `settings` の `run` 文書に覚える（`items` には混ぜない）。覚えた環境が一覧に無ければ選び直させる。
- FR-04 返事の ID を検めてカードに書く。
  - D0042-AC-10 `^session_[A-Za-z0-9]+$` に合う ID だけを `update` で書く。合わなければ書かずにエラー。
- FR-05 二重押しと失敗。
  - D0042-AC-22 返事が来るまで「作る」を無効にする。作った直後は一覧に出るまで動いている扱い。結果が分からないときは、読み直すまでそのカードの「実行」を止める。
  - D0042-AC-13 古いボード（宣言が `list_sessions` だけ）では、ページが「公開し直す必要」と出して壊れず、スキルの「開く」が古さを見つけて公開し直しを勧める。
  - D0042-AC-18（実機）許しを断ると、理由が出て、カードは変わらない。
- FR-06 守ること。
  - D0042-AC-01 ボードが呼ぶ道具は `list_sessions`・`create_session`・`list_environments` の3つだけ。
  - D0042-AC-03 スキルの公開の宣言も、同じ3つの道具にする。
  - D0042-AC-02 `send_message`・`archive_session`・`interrupt_session` の語がボードに無い。
  - D0042-AC-09 外から来た文字は `textContent` で入れる（D0029-AC-04 の検査が新しい部分にも及ぶ）。
  - D0042-AC-11 ボードの URL・実際のセッション ID・手元のパスをスキル・ひな形・この記録に書かない。
- FR-07 文書をそろえる。
  - D0042-AC-12 `/pipe-help` の一覧と、決定の記録の表に載せる。
- D0042-AC-17（実機）許しの画面で `create_session` と `list_environments` を許し、「作る」を押すと、新しいセッションができ、カードに ID が入り、約30秒内に状態が出る。人の許しを得て1回だけ試す（利用料がかかる）。

## 決めたことと理由

- **押せるのは、ボードに書ける人（`data.write`）。** 作る道は確認の画面の「作る」1本だけ。確認の前には呼ばない。
- **送る言葉は編集できる欄で、先頭が `/pipe-in ` でなければ送らない。** `--auto`・`--artifact` は付けない。段の区切りで止まり、続きはセッションで答える。
- **環境は必ず明示する。** ページには呼び出し元のセッションが無く、省くと決まらないため。`source_url` には、ひな形の `REPO`（公開リポジトリの URL）を渡す。
- **選んだ環境は、`items` とは別の `settings` の集まり（文書 ID は `run`）に覚える。** 作れたときだけ書き、書けなくても流れは止めない。`/pipe-plan sync` は `items` だけを読み書きするので影響しない。
- **結果が分からないときは、もう一度作らせない側に倒す。** 「読み直す」を押すまでそのカードの「実行」を止める。失敗のあとに自動でやり直さない。
- **宣言は3つだけ。** 送る・止める・アーカイブは宣言も呼び出しもしない。
- **依存・本体・ジェネレーター・拡張は変えない。** 変えるのは `.claude/skills/pipe-plan/`（ひな形・SKILL.md）、`/pipe-help` の一覧、この記録と表、テストだけ。利用者のプロジェクトを守る仕組み（`guard.py`・`guard_hook.py`）の止める範囲は変わらない。

## 対象外・残った課題

- `send_message` で答えること、セッションを止める・アーカイブすること、複数カードをまとめて実行すること、利用料の見積もりと上限、`permission_mode`・`model` の選び、環境の作成・変更。
- 作ったセッションの権限の既定は、実機で確かめて下に書く。
- 監査・助言で直さなかったもの：公開の前に確認が出ることを公開の手順に書く（助言 V-03）、コネクタの道具の名前が変わったときの手順（V-04）。D0029 の記録が、置き換えで無くなったテストの名前を挙げている（監査 A-02。D0029 は書き換えない）。
- `/pipe-in` を、クラウドのセッションの最初の言葉からスキルとして開けるかは、公式の文書では確かめられなかった。実機（AC-17）で確かめる。
