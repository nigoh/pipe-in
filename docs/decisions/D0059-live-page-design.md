# D0059 進み具合のページ（`/pipe-in --artifact`・`pipe-in live watch`）に、デザインの土台（ブランド「プラグ」）を入れる

## 目的

進み具合のページ（`pipe_in/engine/live_page.py`）は、GitHub 風の色と1文字の印のままで、計画ボード（`board.html`）や `docs/design/` の板（S3 `LiveProgress.dc.html`）と見た目がそろっていなかった。色・文字・状態の表し方を `docs/design/README.md` の決まりにそろえ、明るい画面でも暗い画面でも、色を見なくても状態が分かるようにする。変えるのは見た目だけで、確認待ちのボタン（D0044）と記録の読み方は変えない。

## 機能要件と受け入れ基準

### 機能要件

- FR-01・FR-02：色を役の名前のトークン（`--bg`・`--panel`・`--col`・`--line`・`--fg`・`--muted`・`--coral`・`--teal`・`--blue`・`--bad`・`--ok` と、`board.html` と同じ soft・text の補助）で `:root` に置く。明るいのが既定で、暗いのは `prefers-color-scheme` と `data-theme` の両方で切り替える。
- FR-03：文字は本文を Zen Kaku Gothic New、番号・費用・時刻を JetBrains Mono にする。`board.html` と同じ Google Fonts の `<link>` 2本で読み、代わりの書体も並べる。
- FR-04：段の状態を、Lucide の SVG アイコン（線を `ICONS` に写し、`createElementNS` で作る）・言葉・帯の模様の3つで伝える。言葉は、まだ始まっていない段＝「まだ」、動いている段＝「作業中」、人の判断を待つ段＝「確認待ち」。
- FR-05・FR-06：頭に、ブランドの印・「pipe-in · 進み具合」・「HH:MM 更新」・実行の名前、状態の札（「確認待ち：…」「作業中：…」）と合計を出す。
- FR-07：進み具合の帯（完了＝塗り、確認待ち＝縞、作業中＝点、まだ＝空き）と、状態ごとの数を出す。
- FR-08〜FR-10：段をカード（角の丸み 10）にし、時間は M:SS、角の丸みは札 6・カード 10・面 14・チップ 999。
- FR-11：確認待ちのボタンの見た目をトークンの色にする（承認＝コーラルの塗り、フォーカス＝ティールの輪）。
- FR-12：動きは `prefers-reduced-motion: no-preference` の中だけ。
- FR-13：外から来た文字は `textContent` のまま。D0044 のボタンの出方・送る文・記録の読み方は変えない。

## 決めたことと理由

- **対象は進み具合のページだけ**（人が決めた）。`docs/design/README.md` は画面ごとに `/pipe-in` で進めると決めており、Python だけで閉じていていちばん小さいため。実行パネル・作業台・VSCode の部品は、あとの別の作業にする。
- **外部の読み込みを2つだけ許す**。書体の Google Fonts の `<link>` 2本（`board.html` と同じ文字）と、SVG を `innerHTML` なしで作るのに要る名前空間の文字列 `http://www.w3.org/2000/svg` 1 か所。これで、D0027 の FR-09・AC-47 と D0044 の FR-23・AC-43 の「外部の読み込みなし」を置き換える。検査は、この2つだけを先に取り除いてから、今までの禁止語を全部かける形にした（許す範囲が広がらないことも検査する）。書体が読めない環境でも、代わりの書体で表示は崩れない。
- **印を字形から SVG のアイコンにする**。D0027-AC-86 の「待ち・作業中・確認待ちの印は CSS の形、ほかは1文字」と、言葉の「待ち・実行中」を置き換える。印の大きさの検査は残した。古い見た目を決めていた D0027 のテスト（字形・CSS の形の印・`each_status_has_its_own_mark` など）は、D0059 のテストに書き直して消した。
- **「待ち」をページでは使わない**。`docs/design/README.md` の「待ちは人の判断だけ」に合わせ、人の判断を待つ段を「確認待ち」、まだ始まっていない段を「まだ」と書く（README の該当の行にも足した）。
- **差し戻し＝`undo-2`、不明＝`circle-dashed`**。板に無いので Lucide 1.61.0 の線を写し、`docs/design/README.md` のアイコンの表に足した。帯の模様は、失敗＝赤の塗り、差し戻し＝コーラルの枠だけ、不明＝控えめな色の点線の枠にした。
- **大きさの上限は 40 KB のまま**。アイコンと CSS を足しても収まった（確認用のページで約 36 KB）。
- **「更新なし N分」は入れない**。今回は見た目をそろえることに絞った。
- 番号は D0059（はじめ D0057 で進めたが、並列のほかの作業が D0057・D0058 を使ったので、main に載せ直す前に付け替えた）。
- D0030 の「まだのこと」のうち、進み具合のページへの反映はこれで済んだ（D0030 の本文は歴史として変えない）。
- 受け入れたリスク：claude.ai のアーティファクトの枠で Google Fonts が読めるかは、実機で確かめていない（計画ボードと同じ書き方なので読める見込み）。読めなくても代わりの書体で読める。

### 監査で直したこと

- 監査の5件をすべて直した。D0027・D0044・D0030 の古い記述を置き換えたことをこの記録に書き（A-01・A-02・A-04）、`docs/design/README.md` の「待ち」の行にページでの言い方を足し（A-03）、テストの docstring 2か所の「待ち」を今の言葉に直した（A-05。検査の中身は変えていない）。
- 助言と審査は流していない（変えたファイルに `.claude/`・`plugin/`・`runner.py`・`guard.py`・`guard_hook.py` が無いため）。
