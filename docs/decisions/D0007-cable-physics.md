# D0007 コンセントの上で離しても差さる・流線型のケーブル・引くときはひものように動く

## 目的

パイプ作業台でケーブルをつなぐ人が、プラグをコンセント（電源タップのように縦に並んだ差し込み口）の上まで持っていって離すだけで差せるようにする。あわせて、置いたケーブルを角の無い流線型にし、引いている最中はひものように手元を追いかける動きにして、何をどこへつないでいるかを分かりやすくする。

## 決めたことと理由

- **置いたケーブルは、今のよける通り道をそのまま使い、角を大きく回すだけにした**（人の判断。要件メモの「線形」は書き間違いで、「もう少し流線型に」）。1本のたるんだ曲線にする案は、ブロックの上を通り、ケーブルどうしも重なるのでやめた。半径 24 は、角から曲線までが約 10px で、よける余白（12px）の内側に収まる値。
- **ひもの長さは両端の最短の距離にし、重力は使わない**（人の判断）。たるませると長さの決まりとぶつかる。その代わり、慣性（減衰 0.93）・弱い長さの直し（2回・強さ 0.5）・となりの真ん中へ寄せる力（0.12）で、遅れて曲がり、止めるとまっすぐに戻る動きにした。数は画面で見て決めた。
- **揺れるのは手に持っているケーブルだけ。離したらすぐ置いた形で描く**（人の判断）。差した瞬間には、もとからのプラグの押し込みの動きがある。
- **差す先はコンセントを先に見て、ゆとりは画面の 8px**（人の判断）。コンセントは 15×24px と小さく、縮小して見ているときに合わせにくいため。
- **差す先の判断を DOM（elementFromPoint）から純粋な関数に移した。** コンセントはブロックの外にあり、DOM の部品ではないため。コンセントの外形 `SOCKET_BOX` は view から domain に移し、描く側と判断する側で同じものを使う。
- **引いている間は、手に持っているケーブルの入れ物（`#in-hand`）だけを描き直す。** 毎コマ置いたケーブルの通り道を計算し直さないため。
- **画面の確認で見つけた不具合**：つながっていない段をケーブルの上に引くと、ケーブルがその段をよけて逃げ、間に挟めなかった（前の機能のときから）。引いている間だけ、その段をよける相手から外すようにした（`layoutWires` の `ignore`）。

## 対象外・残った課題

- ひもとブロックのぶつかり、置いたケーブルの揺れ、離したあとの形の移り変わり。
- `/pipe-in` の仕組みの問題：`.claude/hooks/pipe_in_guard.py` は書ける場所の根を `CLAUDE_PROJECT_DIR`（main のフォルダ）で決めるので、worktree の中ではサブエージェントが書けない。また、サブエージェントが報告を返す道具（`SubagentHandback`）も止める。この機能では、要件定義のあとの段をメインが行った。フックは、並行していた作業が [D0004](D0004-pipe-in-guard-worktree.md) で直した。
- 番号：この機能は初め D0004 で進めたが、並行していた作業と重なったので D0007 に付け直した（D0005 は作業中の2つのブランチが使っている）。
