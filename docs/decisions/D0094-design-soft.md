# D0094 デザインの決まりに、文字の大きさ（16px 以上）・押せる所の枠の色 `--edge`・やわらかの角と影を足す（D0030 の角の値を置き換える）

## 目的

画面を `/pipe-design`（D0093）で見直したとき、良さの条件（デジタル庁デザインシステムの文字の基準・WCAG 1.4.11 の部品の対比）に照らすと、今のデザインの決まりは、文字が小さく（12〜15px が中心）、押せる所の枠が薄い（`--line` は地との対比が 3:1 に届かない）ことが分かった。人が見本を触って選んだ「やわらか」（角を大きく、線より影でまとめる）も、決まりにしたいと人が決めた。これを `docs/design/README.md` に書き、ほかの画面を直すときのよりどころにする。

### 要求と前提

- UR-01 pipe-in の画面を直す人として、文字の大きさ・押せる所の枠・角と影の決まりを1か所で知りたい。
- 前提：無し
- 状態を持ち、操作や出来事で移り変わるか
  - 答え：いいえ
  - 理由：デザインの決まりの文書を直すだけで、動くものを足さない。

受け入れ基準は、この記録と `docs/design/README.md` を読むか、差分を見て確かめる（テストは足さない。テストの名前に ID は付けない）。

- FR-01（UR-01）色の表に、押せる所の枠の色 `--edge`（明るい `#8f857e`・暗い `#8a8079`）の行を足す。

- FR-02（UR-01）文字の大きさ（本文と操作 16px 以上・注と札 14px 以上・本文の行間 150% 以上）と、線の濃さ（押せる所の枠は `--edge` で 3:1 以上、`--line` は区切りと押せないまとまりだけ）の決まりを足す。

## 決めたことと理由

- **人が決めたこと**：「やわらか」を、見直した画面だけでなく pipe-in のデザインの決まりにも足す（`/pipe-design` で見直したときに人が選んだ）。文字と線は、良さの条件に合わせる（同じく人が選んだ）。
- **値**：文字の基準は、デジタル庁デザインシステムの「本文・UI は 16 CSS px 以上、14px 未満は原則使わない」に合わせた。`--edge` は、作業台のブロックの枠にすでに使っている色を、押せる所の枠の名前にした（明るい画面の地 `#f6f6f4` と 3.33:1・面 `#ffffff` と 3.61:1・沈んだ地 `#ecebe7` と 3.02:1、暗い画面の面 `#211f1d` と 4.26:1）。沈んだ地の上では余裕が少ないので、押せる所を沈んだ地に置くときは枠を太くするか、地を面にする。
- **選ばなかった形**：今の板と画面を、この件で全部直すこと。キャンバスの板（Design のアーティファクト）と、計画ボード・進み具合のページ・拡張は、それぞれテストと撮影の基準を持つので、画面ごとに次に直すときに入れる。
- **受け入れたリスク**：決まりと、今の画面（まだ直していない画面）が、しばらく食い違う。「直すとき」にそのことを書いた。
