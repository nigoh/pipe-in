# D0013 プラグのロゴの動きを、一拍おいて全体から寄るカメラと、上から差す立体のプラグにする

## 目的

ロゴの動き（`docs/assets/pipe-in-plug-logo.html` と GIF）を見る人が、「どこに何を差したのか」を迷わずに追えるようにする。始まりに止まったロゴを見せ、カメラでコンセントへ目を導き、本物のコンセントと同じく穴の正面からプラグを差す。

## 機能要件と受け入れ基準

- FR-01 外から何も読み込まない、1つのファイルのページのままにする
  - D0013-AC-01 ページに外への script・link・画像・fetch・@import が無い（`tests/test_plug_logo.py::test_d0013_ac01_page_loads_nothing_from_outside`）
- FR-02 カメラ：舞台のどこをどの倍率で映すかを、ばねで追う。型を選べ、はじめは「全体から寄る」
  - D0013-AC-02 カメラの型が5つ（固定・全体から寄る・寄って引く・手持ち・ゆっくり寄る）あり、はじめは全体から寄る。全体図にカメラの枠を出す（`::test_d0013_ac02_camera_presets_and_default`）
  - D0013-AC-08（画面）全体から寄る：止まった全体 → 穴の真上で向きをそろえるころからコンセントへ寄る（約2倍）→ 刃の先が面に当たると面に寄る（約3倍）→ カチッで一瞬押し込む → オレンジが広がるのに合わせて全体へ引く
  - D0013-AC-09（画面）寄っても下の知らせは同じ位置・同じ大きさで、切れない
  - D0013-AC-10（画面）カメラは「速さ」のつまみと一時停止に従う（時刻は物理と同じものを使う）
- FR-03 動き出す前に間を置く
  - D0013-AC-03 はじめは 1.2 秒。つまみで 0〜3 秒に変えられる（`::test_d0013_ac03_pause_before_start`）
  - D0013-AC-11（画面）間のあいだはプラグもカメラも止まり、くり返すたびに間を置く
- FR-04 プラグは穴の正面（手前・上）から差す
  - D0013-AC-04 プラグを立体として描く（影・刃・胴の側面と上面）。横から差すための切り抜き（面の線で刃を消す）は使わない（`::test_d0013_ac04_plug_goes_in_from_above`）
  - D0013-AC-12（画面）運ばれる → 穴の真上で向きをそろえる → 降りて刃の先が面に当たって止まる → 手ごたえのある押し込み → 刃が穴に沈む → 胴の底が面に当たってカチッ → コンセントが少し沈んで戻る、の順に見える。抜くときはまっすぐ上へ

  - D0013-AC-14（画面）動きを減らす設定のときは、差した姿で止まり、カメラは全体を映す
- FR-05 見た目を整える
  - D0013-AC-05 ざらざらの紙の模様を重ねない（`::test_d0013_ac05_no_grain_texture`）
  - D0013-AC-15（画面）オレンジが広がり始める前に、コンセントやプラグが色を変え始めない
- FR-06 GIF と置き場所の説明を、新しい動きに合わせる
  - D0013-AC-06 GIF は幅 800 以下・900KB 以下（`::test_d0013_ac06_gif_size`）
  - D0013-AC-07 `docs/assets/README.md` の表に、カメラと上から差すことが書いてある（`::test_d0013_ac07_assets_readme_describes_motion`）
  - D0013-AC-16 `pytest` が通る

## 動きの設計

時刻は「カチッ」（胴の底が面に当たった時）を 0 にした `tk` と、始まりからの `t` の2つで決める。下の秒は、はじめの設定（速さ 1）のとき。

| 場面 | いつ | プラグ | カメラ（全体から寄る） |
| --- | --- | --- | --- |
| 間 | 始まりから 1.2 秒 | 止まっている | 全体（倍率 1） |
| 運ぶ | t < 0.55 | 持ち上げて、コンセントの左上へ運ぶ。ケーブルは垂れて揺れる | 全体 |
| 狙う | t < 1.3 | 穴の真上（高さ 150）へ。高さ 60 より下では、穴の位置と向きに吸い寄せる | t ≥ 0.7 でコンセントへゆっくり寄る（約2倍） |
| 当たる | t < 1.62 | 降ろして、刃の先が面に当たって止まる（軽く跳ねる） | 面に寄る（約3倍） |
| 押し込む | t < 2.0 | 刃の長さの 6 割まで、じわっと押す（穴の中の手ごたえ） | 面に寄ったまま |
| カチッ | tk = 0 | 押し切って、胴の底が面に当たる。跳ね返りは「プラグの弾み」のつまみ | 一瞬さらに押し込む |
| 広がる | tk 0.08〜1.5 | 差さったまま。コンセントが少し沈んで戻る（0.5 秒） | 広がりに合わせて全体へ引く |
| 抜く | 広がりのあと（フローのときは保存のあと） | まっすぐ上へ抜いて、離す | 抜くところに寄り、全体へ戻る |

- プラグの立体：刃の先の高さを z とし、0 で面に触れ、負で穴に入る。少し斜め上から見るので、高さは画面の上へのずれ（高さ × 0.85）にする。刃の断面は穴より少し小さい形、胴は角の丸い長方形を厚み 52 で立ち上げる。側面と刃は凸包で1枚の形にし、黒を薄く重ねて陰にする。
- ケーブルの端は胴の上面の真ん中。元のロゴの曲線の形を覚えたひもの計算はそのまま。
- カメラは viewBox を動かす。目標の位置と倍率を場面ごとに決め、減衰の強いばね（場面ごとに速さを変える）で追う。舞台の外は映さない。

## 決めたことと理由

- **プラグは上から差す。** コンセントの丸は正面から見た面で、穴は見ている人の側を向いている。前の版は刃を横から滑らせ、面の線で刃を消していたので、上向きの穴に横から差しているように見えた。プラグを少し斜め上から見た立体にし、z（高さ）で降ろして差すことで、本物のコンセントと同じ向きの動きにした。立体の描き方は、3D の部品を足さず、凸包と影だけで作った（外から何も読み込まないため）。
- **差したあとは、プラグの胴がコンセントの点を覆う。** 止まったロゴ（`pipe-in-logo.svg`）は、プラグがコンセントの横にある絵のまま。動きの終わりと止まったロゴが違う形になることは受け入れた（揃えるかは残った課題）。
- **カメラは「全体 → 寄る → 引く」。** 始まりから寄ると、何のロゴかが分からないまま細部を見ることになる。まず全体を見せ、狙うところからコンセントへ寄せて目を導き、広がりで全体に戻して、ロゴとして終わる。ほかの型（固定・寄って引く・手持ち・ゆっくり寄る）は比べるために残した。
- **始まりに間を置く。** 開いてすぐ動くと、止まったロゴを見る前に動きが始まって早く感じる。1.2 秒止めてから動かす。長さはつまみで変えられる。
- **ざらざらの模様はやめた。** 紙の質感として重ねていた粒と繊維の模様は、画面では汚れのように見えたため外した。試しに作った「切り紙」の質感（色紙の繊維・厚み・影）も、ロゴの動きの見やすさを優先して入れなかった。
- **広がる前の色の変わり始めを直した。** 色を変える範囲に 60 のゆとりがあり、広がる前（半径 0）でもコンセントの近くが少し白く混ざっていた。半径が 0 のときは混ぜない。
- **GIF は 1 秒に 15 枚・40 色。** はじめの間を入れて約6秒になったので、前の 20 枚では 900KB を超えた。同じ絵が続くところは1枚にまとめている。

## 対象外・残った課題

- 止まったロゴ（`pipe-in-logo.svg`・`pipe-in-logo-dark.svg`）を、差した姿に合わせるか。合わせない場合、プラグの胴を小さくして緑の点が見えるようにするか。
- 見る角度（斜め上の度合い）と、押し込む長さ（今は約 0.4 秒）の調整。
- 「フローまで見せる」のときのカメラは「寄って引く」と同じ追い方のまま。作業台の場面ごとの見せ方は決めていない。
- 作業台の小さなプラグ（フローの中）は、横向きのコンセントに横から差す形のまま（そちらは差し込み口が横を向いているので正しい）。
- 暗い表示の GIF は作っていない。

## 確かめたこと

- `pytest`：全部通った（`tests/test_plug_logo.py` は、前の版で AC-02〜05・07 が期待した理由で落ちることを先に確かめた）。
- 画面（Playwright・Chromium）：明るい表示と暗い表示で、間 → 運ぶ → 狙う → 当たる → 押し込む → カチッ → 広がる、をコンセントの近くと全体の両方で撮って確かめた。コンソールのエラーは無い。カメラの型ごとの寄り方と、全体図の枠が動くことを確かめた。
- 画面：動きを減らす設定（Playwright の reducedMotion）で開き、差した姿で止まり、カメラが全体を映すことを確かめた（最初はカメラが寄ったまま止まっていたので直した）。
