# デザイン

pipe-in の画面（計画ボード・実行パネル・進み具合のページ・パイプ作業台）の見た目の土台です。ブランドは「プラグ」（今のロゴの差し込むプラグの色）に決めました。決めた理由は [D0030](../decisions/D0030-brand-plug.md) にあります。

`canvas/` は、Claude のデザインのキャンバス（Design の型のアーティファクト）の写しです。`canvas.json` が目次で、1 枚の板が 1 つの `.dc.html` です。板は Design の型の実行部品（`./support.js`）の上で描かれるので、ブラウザで直接開いても絵にはなりません。キャンバスで直したら、ここにも写し直します。

## 色の決まり

色は役の名前で呼び、明るい画面と暗い画面で同じ名前に別の値を当てます。

| 役 | 名前 | 明るい | 暗い |
| --- | --- | --- | --- |
| 地 | `--bg` | `#f6f6f4` | `#161514` |
| 面 | `--panel` | `#ffffff` | `#211f1d` |
| 列 | `--col` | `#ecebe7` | `#1d1b19` |
| 線 | `--line` | `#e4ded8` | `#36322f` |
| 文字 | `--fg` | `#23201e` | `#f2ece6` |
| 控えめな文字 | `--muted` | `#6b625c` | `#ada39b` |
| 差す（コーラル） | `--coral` | `#c2471f` | `#ff8a65` |
| 流れる（ティール） | `--teal` | `#167d6b` | `#5fc4ab` |
| 見てほしい | `--blue` | `#3f6fb0` | `#8db4ee` |
| 失敗 | `--bad` | `#b3261e` | `#ff8a80` |
| 完了 | `--ok` | `#2e7d32` | `#81c784` |

- **コーラルは「人が手を出す」ところ**：保存などの主のボタン、あなた待ち・確認待ち、手で確かめる、作業台のプラグ、差し戻しのケーブル。
- **ティールは「流れている・選んでいる」ところ**：作業中・進行中、選んだときの輪、次の段のケーブル、並列の枠。
- **状態は色だけで伝えない**：印（▲ あなた待ち、● 作業中、◆ 見てほしい、✕ 失敗、✓ 完了）と言葉を添えます。
- **文字**：見出しと本文は Zen Kaku Gothic New、番号・費用・時刻は JetBrains Mono。
- **角の丸み**：札 6、カード 10、面 14、チップ 999。影はカードにうすく、引いている間と窓だけ持ち上げる。
- **ケーブル**（作業台）：次の段＝ティールの実線、分岐＝青の一点鎖線、差し戻し＝コーラルの破線、並列の枠＝ティールの破線の枠。色に加えて線の形でも見分けられる。
- **ケーブルの引き方**（作業台）：曲線にせず、縦と横の直線で引き、曲がり角だけ緩く丸める（半径 12px ほど）。線の端はブロックの左の差し込み口と右のプラグにそろえる。
- **コンセントとプラグ**（作業台。ロゴから）：ブロックの左にティールの丸いコンセント（穴2つ）、右にコーラルのプラグ（胴と刃2本）。穴と刃は同じ向き（横）。つないだ所は、プラグがコンセントに差さった形で描く。差すときは、近づくと差せるコンセントだけが光り、差した瞬間に輪が一度広がる（動きを減らす設定では輪だけ）。
- **ブロックの形**（作業台）：フロー図の決まりに合わせる。仕分け＝ひし形（名前は下）、確かめる＝六角形、外を見る＝平行四辺形、文書と図＝書類の形、任せる＝両端に線のある四角、並列の枠＝二段の枠。
- **ケーブルが重なったとき**：交わる所は上の線に地の色のふちを付けて下の線を切る、同じ道は 8px ずつずらす、分かれる・合わさる所にだけ点、選んだ線だけ太くしてほかはうすく。
- **ボタンの文字**：高さは決めず、最小の高さ（36px など）と上下の余白で作る。文字が折り返したらボタンが縦に伸び、文字は必ずボタンの中に収まる。
- **作業台の図の地**：ブロックより一段沈めた色（明るい `#eceae6`・暗い `#100f0e`）に薄い点。ブロックは面の色に濃いめの枠（`#8f857e`・`#8a8079`）とうすい影で浮かせる。

## ページと板

| ページ | 板 | 中身 |
| --- | --- | --- |
| ブランド候補 | `Main.dc.html` | 5 案の比較 |
| | `Plug.dc.html` | 案1 プラグ（決めた案） |
| | `Blueprint.dc.html`・`Signal.dc.html`・`Aizome.dc.html`・`Terminal.dc.html` | 案2 配管図・案3 信号・案4 藍染・案5 端子台（選ばなかった案） |
| コンポーネント | `Foundations.dc.html` | 01 基礎：色・文字・間隔・角・影 |
| | `Controls.dc.html` | 02 操作：ボタン・チップ・入力 |
| | `Status.dc.html` | 03 状態：札・進み具合・知らせ |
| | `Cards.dc.html` | 04 組み合わせ：カード・列・セッション・編集の窓 |
| | `Workbench.dc.html` | 05 作業台：ブロック・ケーブル・差し込み口 |
| 画面 | `RunPanel.dc.html` | S1 実行パネル（図と出力。確認待ちのとき） |
| | `RunArtifacts.dc.html` | S2 実行パネル（成果物のタブ。更新が止まっているとき） |
| | `LiveProgress.dc.html` | S3 進み具合のページ（`/pipe-in --artifact`。広い画面とスマホの幅） |
| | `PlanBoard.dc.html` | S4 計画ボード（`/pipe-plan`） |
| | `WorkbenchScreen.dc.html` | S5 パイプ作業台 |
| | `VSCodeBits.dc.html` | S6 VSCode の小さな部品（ステータスバー・知らせ・コマンドの一覧） |

コンポーネントと画面の板は、どれも明るい画面と暗い画面を左右に並べています。画面の中の名前・件数・費用は見本で、本物の記録ではありません。

## 直すとき

- 色や部品を変えるときは、まず `Foundations.dc.html` と上の色の表を直し、ほかの板をそれに合わせます。
- キャンバスで直したら、`canvas/` に写し直します（`canvas.json` の `boards` と `order` は、`canvas/` の `.dc.html` とちょうど同じにします。`tests/test_design_docs.py` が確かめます）。
- キャンバスの URL、セッションの ID、手元のセッションやブランチの名前は書きません（公開リポジトリのため）。
- この土台をコードに入れるのは、画面ごとに `/pipe-in` で進めます（計画ボードは `.claude/skills/pipe-plan/board.html`、進み具合のページは `pipe_in/engine/live_page.py`、実行パネルと作業台は `vscode/`）。
